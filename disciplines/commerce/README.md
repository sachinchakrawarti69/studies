# Accounting Learning Path 
 
Complete accounting curriculum organized from NCERT Class 11 to Advanced topics. 
 
## Folder Structure Overview 
- **01_class_11_ncert**: Complete Class 11 NCERT Accounting (Parts A and B) 
- **02_class_12_ncert**: Complete Class 12 NCERT Accounting (Company Accounts and Cash Flow) 
- **03_financial_accounting_advanced**: Accounting Standards, IND AS, IFRS, Consolidation 
- **04_cost_accounting**: Cost Basics, Material, Labour, Overhead, Methods, ABC, Marginal, Standard 
- **05_managerial_accounting**: Budgeting, Decision Making, Performance Management 
- **06_advanced_accounting_topics**: Partnership, Government, Forensic, Financial Modeling, Ethics, International 
- **07_practical_cases_and_projects**: Class 11/12 Problems, Case Studies, Projects 
- **08_reference_materials**: Formula Sheets, Software Guides, Career Resources 
- **09_question_bank**: Chapter-wise Questions, Competitive Exam Questions, Mock Tests
